# Changelog

## 0.1.0 — 2026-09-05

- First MVP: LOC Chronicling America fetcher, OCR junk scorer, local-crumb bias,
  CLI (`hunt` / `show` / `pack` / `serve` / `score`), static gallery UI.
- Challenge cards require **3 chaining clues** (C1→A, C2 uses A→B, C3 uses B→answer)
  aimed at unique small-town crumbs, not famous national events.
- Sample fixtures with synthetic bad OCR + real loc.gov page URLs.
